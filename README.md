# BAD App

One player card for every BADDIE. Sign up, join sessions, earn points, and run the courts.

- Live site: https://the-bad-club.github.io/bad-app/
- Hosting: GitHub Pages (free). Data and sign-in: Firebase Spark plan (free).

## Files
- `index.html` — the built app (generated by `build.py`, don't edit by hand)
- `config.js` — Firebase project keys and organiser emails
- `firestore.rules` — paste into Firebase → Firestore Database → Rules
- `seed.json` — starter sessions, posts and sample players, loaded the first time an organiser signs in to an empty database
- `src/` — hosted-only pieces (Firebase sign-in bridge, sign-in styles)

## Adding an organiser
Add their email to `BAD_ADMINS` in `config.js` **and** to the list in `firestore.rules`, or create a document `admins/<their email>` in Firestore.
